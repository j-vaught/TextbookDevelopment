\caption{Gradient descent on a quadratic function $f(\vecx) = x_1^2 + 4x_2^2$. The elliptical contours represent level curves of constant function value. Starting from initial point $\vecx_0 = (2.5, 1.2)$, gradient descent iteratively moves in the direction of steepest descent (negative gradient, shown in Atlantic blue). The zigzag pattern (Garnet path) is characteristic of gradient descent on ill-conditioned problems where the contours are elongated ellipses. Each step moves perpendicular to the local level curve, eventually converging to the global minimum at $\vecx^* = (0, 0)$ (Horseshoe green).}
\label{fig:contour_gradient}
