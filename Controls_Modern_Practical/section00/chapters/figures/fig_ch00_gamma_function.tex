\caption{The Gamma function $\Gamma(x)$ extends the factorial to real (and complex) numbers via the integral $\Gamma(x) = \int_0^\infty t^{x-1}\ee^{-t}\,\dd t$ for $x > 0$. Key properties: (1) $\Gamma(n) = (n-1)!$ for positive integers (Horseshoe markers); (2) Recurrence relation $\Gamma(x+1) = x\Gamma(x)$; (3) Special value $\Gamma(\frac{1}{2}) = \sqrt{\pi}$ (Congaree marker); (4) Simple poles at non-positive integers $x = 0, -1, -2, \ldots$ (Rose dashed lines). The function has a unique minimum at $x \approx 1.462$ where $\Gamma(x) \approx 0.886$.}
\label{fig:gamma_function}
