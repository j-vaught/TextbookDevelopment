\caption{Bessel functions of the first kind $J_n(x)$ for orders $n = 0, 1, 2$. These functions arise in problems with cylindrical symmetry, including heat conduction, vibrating membranes, and electromagnetic waveguides. Key features: $J_0(0) = 1$ while $J_n(0) = 0$ for $n \geq 1$; all functions exhibit damped oscillatory behavior with amplitude decaying as $1/\sqrt{x}$. The zeros $j_{n,k}$ (marked points) determine natural frequencies in boundary value problems.}
