Convergence and Termination\n\n### 5.1 Detecting Convergence in Noisy Settings\n\nYour evaluation metric (YOLO mAP on real data) has inherent noise from:\n- Stochastic training\n- Synthetic data sampling variation\n- Evaluation set variance\n\n**Methods to detect convergence:**\n\n1. **Exponential Moving Average (EMA)** of best objective\n   - Track EMA with α=0.1\n   - Stop when `EMA_improvement < threshold` for `patience` iterations\n\n2. **Statistical Tests**\n   - Track last N objective values\n   - Use [WilcoxonPruner](https://optuna.readthedocs.io/en/stable/tutorial/10_key_features/003_efficient_optimization_algorithms.html) from Optuna\n   - Stop when improvement is not statistically significant\n\n3. **Trust Region Shrinkage**\n   - If using TuRBO, monitor trust region size\n   - Convergence indicated when regions shrink below threshold\n\n### 5.2 Recommended Stopping Criteria\n\n```python\nclass ConvergenceChecker:\n    def __init__(self, patience=10, min_improvement=0.001, \n                 max_iterations=50, min_iterations=20):\n        self.patience = patience\n        self.min_improvement = min_improvement\n        self.max_iterations = max_iterations\n        self.min_iterations = min_iterations\n        self.best_values = []\n        self.no_improvement_count = 0\n    \n    def should_stop(self, current_value, iteration):\n        # Never stop before minimum iterations\n        if iteration < self.min_iterations:\n            return False\n        \n        # Always stop at maximum iterations\n        if iteration >= self.max_iterations:\n            return True\n        \n        # Check for improvement\n        if len(self.best_values) > 0:\n            best_so_far = max(self.best_values)\n            if current_value > best_so_far + self.min_improvement:\n                self.no_improvement_count = 0\n            else:\n                self.no_improvement_count += 1\n        \n        self.best_values.append(current_value)\n        \n        # Stop if no improvement for patience iterations\n        return self.no_improvement_count >= self.patience\n```\n\n### 5.3 Expected Iterations to Convergence\n\nBased on research and typical BO behavior:\n\n| Parameter Dimensions | Expected Iterations | 90% Confidence Range |\n|---------------------|--------------------|-----------------------|\n| 3-5 parameters | 20-30 | 15-50 |\n| 6-10 parameters | 30-50 | 25-80 |\n| 11-20 parameters | 50-100 | 40-150 |\n\n**For your use case** (likely 5-10 synthetic data parameters): **Expect 25-40 iterations** to reach near-optimal, with diminishing returns after 50.\n\n---\n\n## 6.
